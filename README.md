# La Fabrique

Le poste de pilotage d'un projet logiciel construit avec Claude : documentation en ligne, stories, ce qui attend la production, et un circuit de demande suivi et traçable, du besoin écrit par un Product Engineer jusqu'à la version en production.

Une couche fine sur GitHub : les stories restent des issues, le code des branches, les déploiements des workflows du projet. Chaque projet piloté se décrit dans un fichier `.fabrique.json` à la racine de son dépôt ([format](docs/fabrique-json.md)).

Principes, rôles et architecture : [CLAUDE.md](CLAUDE.md).

Premier projet piloté : [L'épicerie extraordinaire](https://github.com/serge-fantino/epicerie-extraordinaire).

Mise en route (anglais) : [docs/owner-setup.md](docs/owner-setup.md).
