# Personal data

- **The person's La Fabrique link** (access and refresh tokens): kept by the project's server only, never sent to the browser nor exported; removed when the person unlinks, or when La Fabrique refuses it.
- **A report**: the issue on GitHub carries the person's GitHub login, the page's path, the part picked (its selector and text), the screen size, the browser, recent JavaScript errors, and the screenshot if the person adds one (kept by La Fabrique at an address impossible to guess). Nothing the person typed in the app's fields.
- **Recorded steps**: page paths, the names of buttons, links and fields; never a value typed or chosen, never a screenshot. Kept in La Fabrique's log with the tester's login, the story, the criterion and the version.
- **Offline**: a report not yet sent stays in the device's storage until it is sent.
